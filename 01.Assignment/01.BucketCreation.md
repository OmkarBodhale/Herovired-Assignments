# Create S3 bucket
Steps:
1. login to AWS account and go on S3 bucket creation page
2. Select General Purpose Bucket and Provide a meaning fulname
3. Enable ACL ---This will provide us to apply access rule over each indivisual file
4. Bydefault S3 Bucket is blocked for public accesss de-select the Block all public access option ---This will allow public to access the file through the URL
5. Enable bucket Versioning ---this will maintain versions of the files uploaded or modificed
6. create on create bucket
