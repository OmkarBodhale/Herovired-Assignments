# User Creation with S3 Bucket Object fetching access and Deleting the same
1. Create a new user using IAM Service <img width="1910" height="822" alt="image" src="https://github.com/user-attachments/assets/bb504a9d-3be5-4111-a657-c7b38ca0a8ed" />
2. Provide a good name to the use and also select password creation checkbox by default auto password creation option is enabled. click on next
3. We will first create policy which will be allow access to list s3 objects and delete 
4. Apply below policy. note : Pass the bucket name whcih we created in the first step with <<your-bucket-name>>
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowBucketListing",
      "Effect": "Allow",
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::<<your-bucket-name>>"
    },
    {
      "Sid": "AllowObjectDeletion",
      "Effect": "Allow",
      "Action": "s3:DeleteObject",
      "Resource": "arn:aws:s3:::<<your-bucket-name>>/*"
    }
  ]
}
