NOTE :- In production, S3 Lifecycle Rules natively handle the expiration and deletion of objects with zero code and lower operational overhead. However, you should use Lambda instead when your deletion logic requires complex conditions (e.g., deleting files based on custom regex naming patterns), cross-service lookups (e.g., checking a database table before deleting an associated file), or executing custom logging and notifications upon deletion.
